# Dashboard de Business Intelligence: Plataforma de Delivery

![Overview](https://github.com/Raphael-HFerreira/delivery-analytics-bi/blob/main/Screenshots/01-overview.jpg)

## 📊 Sobre este Projeto

Dashboard estratégico desenvolvido e liderado para uma **grande plataforma de delivery** (concorrente direto do iFood).

**Objetivo:** Consolidar 7 anos de dados (2018-2025) em um sistema de BI que permitisse aos CEOs tomar decisões data-driven sobre retenção, faturamento e segmentação de clientes.

## 💡 Insights Principais

### 1. Churn Estruturado por Ciclo de Vida
**Achado:** 37,21% dos churners tiveram 1+ ano de permanência. Não é fuga inicial, é abandono após tentativa de estabelecimento.  
**Ação:** Programa de health-check nos meses 3, 6 e 12 para intervir antes do ponto crítico.

### 2. Sazonalidade Econômica Clara
**Achado:** Faturamento pico em maio/2020 (R$ 0,5 Mi), seguido de queda gradual. MRRLost oscila 2-10 Mi com spike em 2022.  
**Ação:** Planejamento trimestral de retenção alinhado com períodos sazonais.

### 3. Concentração por Categoria
**Achado:** Pizzaria domina com 26% (R$ 145 Mi). Restaurantes geram 12% do churn (140 casos), desproporcionalmente ao faturamento.  
**Ação:** Produto customizado para restaurantes com modelo econômico adaptado.

### 4. Adimplência Robusta
**Achado:** 89,35% dos clientes em dia. Modelo de crédito estruturado e confiável.  
**Ação:** Base saudável para estratégia agressiva de crescimento.

### 5. Distribuição Geográfica com Potencial
**Achado:** Manaus (298), Belo Horizonte (147), São Paulo (39). Presença em 15 segmentos.  
**Ação:** Expansão vertical em cidades de baixa penetração; estratégia regional customizada.

## 🛠 Tecnologias & Stack

- **Power BI Desktop** — Desenvolvimento do dashboard e visualizações
- **DAX** — Cálculos avançados (MRRLost, Churn Rate, Ticket Médio ponderado)
- **SQL** — Consolidação de 7 anos de múltiplas tabelas
- **Modelagem de Dados** — Arquitetura em snowflake schema (tabelas de fato + dimensão)

## 📥 Como Usar Este Projeto

### Opção 1: Visualizar (Mais Fácil)
Veja as screenshots das 4 abas neste README. São capturas em alta resolução do dashboard completo.

### Opção 2: Abrir o Dashboard (Com Power BI)
1. Baixe o arquivo `dashboard.pbix`
2. Abra no **Microsoft Power BI Desktop** (download gratuito: https://powerbi.microsoft.com)
3. Conecte com suas fontes de dados ou use os dados de exemplo inclusos
4. Explore as 4 abas e filtros dinâmicos
